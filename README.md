# midocescolar
Herramienta web gratuita y privada de procesamiento de documentos escolares. Convierte fotos a PDF formato carta, une múltiples archivos y optimiza el peso a menos de 1 MB de forma 100% local en el navegador, sin subir tus datos a servidores. Diseñada para docentes y estudiantes en trámites de USICAMM, SEP y admisiones universitarias.
